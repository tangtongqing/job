## 二、主要冲突与裁决

| 冲突 | 旧资料表述 | 当前证据 | V2.0 裁决 |
|---|---|---|---|
| 数据源 | 支持 BOSS、牛客等主流平台采集 | 当前只启用公开 ATS API；受限平台禁用 | 本期只承诺公开 ATS + 演示快照 |
| 收藏 / 待投递关系 | 互斥升级，投递后全部移除 | 当前实现为独立意图；创建投递只结束待投递 | 以当前实现为准，并把收藏自动结束列为待决策 |
| 移动端 | 1024px+，更窄仅降级 | 当前章程和验收要求核心流程 390px 可用 | 本期纳入响应式核心流程 |
| 订阅 | 新岗位高亮和未读通知 | 当前仅保存规则，明确写通知下一阶段 | F-07 只承诺规则 CRUD |
| DDL 提醒 | 3 天 / 1 天 / 当天主动提醒 | 当前只有岗位截止时间展示和计划事件待办 | 本期承诺近期安排，不承诺外部通知 |
| 纠错 | 任何状态均可从产品中纠错 | 后端可纠错，前端无入口 | 作为 P0 目标缺口，不能写成已完整实现 |
| 高级筛选 | UI 支持毕业年份、学历、经验等 | API 有字段，当前 UI 只展示关键词/公司/地点 | 本期 UI 只承诺 3 个条件；其他移入未来目标 |
| 看板价值 | 作为核心价值并已解决复盘问题 | 只有少量公开行为证据，无真人效果 | 保留已实现功能，成功指标必须通过真人验证 |
| 用户研究 | 画像描述容易被误读为真实访谈 | 3 人访谈结果文件为空；合成角色明确非真人 | 统一使用“行为分群/假设画像”，真人样本记为 0 |

## 三、文档分类建议

| 分类 | 文档 | 建议 |
|---|---|---|
| 保留 | `docs/product/MRD.md` | 市场与机会的权威入口；PRD 只引用结论 |
| 保留 | `docs/research/*` | 原始研究和研究限制，不能合并删除 |
| 保留 | `docs/design/DESIGN.md`、`shape-*.md` | 页面和视觉细节的权威入口 |
| 保留 | `docs/architecture/*` | 技术实现、数据结构和 API 细节 |
| 保留 | `docs/qa/*`、`docs/engineering/*` | 验证事实和实施记录 |

| 引用 | `docs/product/JTBD.md`、`PERSONAS.md` | 作为假设与行为分群来源，不复制成长篇 PRD 正文 |
| 合并候选 | `docs/product/PRD.md` | 当前需求应由新 PRD 接管；旧文件保留为历史基线 |
| 归档候选 | `docs/product/PRD.md` | 获得权限后移入 `docs/archive/` 并加版本说明 |
| 修改候选 | `README.md`、`docs/README.md` | 获得文档整理权限后，把 PRD 入口改为新文件 |
| 删除候选 | 无 | 未发现可在“仅建议”权限下安全删除的文件 |
