## 存档规则

1. 当前结论只维护在稳定入口中，存档文件不继续迭代。
2. 需要恢复历史内容时优先使用 Git；仅保留具有决策或审计价值的快照。
3. 代理过程文件、临时截图和可再生成产物不进入存档。
4. 存档文件中的旧路径可能只代表当时结构，当前入口以本页映射为准。
