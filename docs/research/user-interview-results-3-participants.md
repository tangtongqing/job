## 2. 记录与引用规则

每条研究材料使用以下标签：

| 标签 | 含义 | 示例 |
|---|---|---|
| `OBS` | 参与者实际做过、展示过或按时间顺序讲述的行为 | `OBS-P01-01` 最近一次连续三天查看公司 A 官网 |
| `EXPL` | 参与者对自己行为的解释 | `EXPL-P01-01` 认为公众号更新更快 |
| `QUOTE` | 可由录音或当场逐字笔记核对的匿名原话 | `QUOTE-P01-01`，必须记录依据和同意范围 |
| `INF` | 研究者基于证据形成的推断 | `INF-01` S1 可能只在招聘窗口高频使用 |
| `COUNTER` | 与现有产品假设冲突的反例 | `COUNTER-01` 书签已足够且从未遗漏 |
| `DEC` | 项目所有者基于证据作出的产品决定 | `DEC-01` 暂缓通知功能 |

不得把 `EXPL` 或 `INF` 加引号冒充用户原话，也不得在没有事件依据时把态度写成 `OBS`。
