# JobPulse P0 闭环缺口：实现计划

## 阶段 1：招聘通知时间进入近期安排

- 扩展 AI 解析结构、提示词和正则降级时间提取；
- 扩展解析接口与前端结果展示；
- 扩展单条状态流转契约；
- 在一个事务中写状态事件与面试/测评计划事件；
- 增加解析、事务、时间线和待办回归测试。

## 阶段 2：岗位库外投递补录

- 增加规范化的外部投递请求模型；
- 增加原子创建手动岗位、投递及初始事件的接口；
- 在投递管理页增加内联补录表单；
- 创建成功后进入新投递详情；
- 增加字段校验、重复进行中投递与原子创建测试。

## 阶段 3：产品级验证与研究结论回写

- 运行后端全量测试；
- 运行前端 lint 与生产构建；
- 启动本地服务，用浏览器复测两个 P0 用户路径；
- 保存复测截图；
- 更新公开情景研究报告中的缺口状态和剩余限制。

## 回退与风险控制

- 不新增数据库表或迁移，复用现有 `Job`、`Application`、`ApplicationEvent`。
- 不改变批量状态流转语义；计划事件只由单条确认流程创建。
- 不自动执行邮件建议，避免错误解析直接污染进度。
- 不触碰营销页与案例页文件。
