## 当前可演示闭环

`发现岗位 → 收藏 / 待投递 → 创建投递 → 更新状态 → 计划事件 → 近期安排 → 看板复盘`

同时通过：

- 公开 ATS 岗位采集、来源状态和字段完整度；
- 岗位筛选、分页、详情、完整 JD 与官方申请链接；
- 收藏与待投递两类独立意图；
- 岗位库外投递补录；
- 投递状态流转、纠错和事件时间线；
- 招聘通知解析建议，用户确认后原子写入状态与计划事件；
- 岗位订阅 CRUD 与空条件校验；
- Demo 数据二次确认重置；
- 官网视频控制、亮暗主题与响应式布局。

## 数据与合规核对

- 标准公开演示数据：24 条确定性岗位快照、5 条投递、2 条收藏、2 条待投递、3 条订阅；
- 本地可从 Figma、Webflow、Intercom、Stripe 的公开 Greenhouse API 采集真实岗位；
- 岗位保留完整 JD、来源和官方投递链接；
- 线上匿名采集触发关闭；
- BOSS、牛客等受限平台保持禁用，不绕过登录、验证码或反爬；
- 线上未配置 LLM 或邮件服务密钥，邮件文本只做本地正则降级解析；
- 公开版本没有账号隔离，所有访客共享演示数据。
