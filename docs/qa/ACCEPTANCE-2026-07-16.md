## 非阻塞问题

1. **P2 · 空订阅提交反馈不明确**：后端正确返回 400，规则不会被创建；前端未显示清晰的就地校验提示。建议禁用空表单提交或显示“至少填写一个条件”。
2. **P3 · 真实岗位自动核验尚未实现**：当前 `last_verified_at` 覆盖率为 43%，来自确定性快照。长期版本应加入真实链接定期核验、失效下架和刷新策略。
3. **P3 · Python 技术债**：全量测试通过，但仍有 `datetime.utcnow()` 与 SQLAlchemy 旧接口弃用警告，不影响演示。
