# 求职管理工具产品设计

一个面向大学生与应届毕业生的轻量化求职管理工具产品设计项目。  
本项目围绕求职过程中常见的 **岗位信息分散、投递进度难跟踪、待办事项易遗漏** 等问题，完成了从需求分析、功能拆解、MVP 设计到低保真原型输出的一整套产品方案。

## 项目背景

在求职过程中，用户通常需要同时管理多个岗位信息、投递进度、面试安排、材料提交、简历修改等内容。  
这些信息往往分散在招聘平台、聊天记录、备忘录、日历和本地文档中，容易导致：

- 岗位信息分散，缺乏统一记录
- 投递进度难以跟踪
- 面试、笔试和待办事项容易遗漏
- 求职节奏难以整体掌握

因此，本项目设计了一款 **求职管理工具**，希望通过“岗位管理 + 待办管理 + 首页总览”的方式，帮助用户更高效地管理求职过程。

---

## 项目目标

本项目的目标是设计一个适合大学生求职场景的轻量化工具，优先验证以下核心价值：

1. 帮助用户统一记录岗位信息  
2. 帮助用户跟踪不同岗位的求职进度  
3. 帮助用户管理面试准备、材料提交等关键待办事项  
4. 帮助用户通过首页快速掌握整体求职状态  

---

## 目标用户

- 正在找实习的大学生
- 正在准备春招 / 秋招 / 校招的应届毕业生
- 同时在多个平台投递岗位、需要统一管理求职进展的用户

---

## MVP 核心功能

### 1. 首页总览
- 查看岗位总数及不同阶段岗位数量
- 查看近期待办事项
- 查看即将到来的面试 / 笔试安排
- 快速进入新增岗位 / 新增待办流程

### 2. 岗位投递管理
- 新增岗位记录
- 查看岗位列表
- 按进度筛选岗位
- 编辑岗位信息
- 删除岗位记录
- 查看岗位详情

### 3. 岗位详情跟进
- 查看岗位基础信息
- 查看岗位要求
- 记录备注与跟进信息
- 查看相关待办事项
- 更新岗位进度

### 4. 待办事项管理
- 新增待办事项
- 查看待办列表
- 按状态筛选待办
- 编辑待办事项
- 更新待办状态
- 删除待办事项

## 竞品分析方向

本项目在设计过程中主要参考了两类产品：

### 招聘平台类
- BOSS直聘
- 智联招聘
- 前程无忧

### 通用任务管理类
- 飞书待办
- 滴答清单
- Notion

分析结论是：

- 招聘平台更擅长岗位浏览和投递，但缺少对用户个人求职过程的持续管理  
- 通用任务工具擅长任务记录和提醒，但缺少岗位信息结构化管理  
- 本项目的机会点在于将 **岗位管理** 与 **待办管理** 结合，形成更贴近求职场景的轻量化工具

---

## 项目价值

本项目的核心价值不在于提供更多岗位，而在于：

- 帮助用户统一管理已进入求职流程的岗位信息
- 帮助用户减少任务遗漏和时间节点遗漏
- 帮助用户更高效地掌握整体求职节奏
- 用更聚焦的场景设计替代通用工具的高配置成本
