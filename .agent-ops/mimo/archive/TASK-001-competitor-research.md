# TASK-001 · 竞品调研（招聘信息聚合 + 投递管理赛道）

## 背景与目标

本项目是一个面向大学生的**招聘信息聚合 + 投递管理工具**，同时作为产品经理求职作品集支撑。
当前处于阶段 1（产品定义），需要一份**标准深度的竞品调研**，覆盖直接竞品与相邻产品，输出可供作品集讲述的结构化报告。

**目标**：识别赛道主流玩家的定位、功能、商业模式与优劣，提炼对本项目的差异化启示。

## 实现要求

### 1. 竞品清单（覆盖 6 个，至少包含以下）

**直接竞品（招聘信息聚合 / 求职工具）**：
1. 牛客网（校招/面经/招聘）
2. 实习僧（实习聚合）
3. 看准网 / 脉脉（公司点评 + 招聘）
4. 超级简历 /简历啦啦（简历 + 投递管理，二选一或都做）

**相邻 / 海外参考**：
5. LinkedIn Jobs（海外标杆，聚合 + 投递追踪）
6. BOSS直聘 或 拉勾（主流招聘平台，看其"职位订阅/投递记录"功能）

> 如调研中发现更典型竞品可替换，但需在报告中说明理由。

### 2. 每个竞品的分析维度（统一模板）

```
## <竞品名>

### 基本信息
- 定位（一句话）
- 目标用户
- 商业模式（免费/会员/广告/招聘方付费）
- 体量量级（用户/DAU 估算，有则写，无则标注"未知"）

### 核心功能（按模块列）
- 信息采集/聚合方式
- 检索与筛选能力
- 投递管理 / 状态追踪
- 数据看板 / 统计
- 个性化订阅 / 推送
- 其他差异化功能

### 优势
- 3-5 条，具体到功能或体验

### 不足 / 用户吐槽点
- 3-5 条，优先来自公开评价（App Store/知乎/小红书吐槽）

### 对本项目的启示
- 1-3 条，明确"借鉴什么 / 避免什么 / 差异化什么"
```

### 3. 横向对比与结论

- **功能矩阵表**：6 个竞品 × 5 个核心功能维度（采集聚合 / 检索筛选 / 投递管理 / 看板 / 订阅），标注有/无/强弱
- **市场空白点**：综合分析后指出 2-3 个"现有产品都没做好、而本项目可以切入"的机会点
- **差异化定位建议**：给本项目一句话差异化定位，并说明支撑理由

### 4. 格式与质量要求

- Markdown 格式，结构清晰，可被作品集直接引用
- 信息要有**来源依据**（标注"官网/应用商店/公开评测"），不要凭空臆测
- 优劣分析要**具体**（避免"功能丰富""体验一般"这类空话）
- 结论要有**可执行性**（启示要能落到功能设计上）
- 中文撰写
