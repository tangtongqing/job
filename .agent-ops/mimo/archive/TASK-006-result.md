## 关键架构决策

### 应用形态
- **单体应用**，模块化分层（api/core/crawler/db）
- 前后端分离：Next.js 14 (App Router) + FastAPI 0.110+
- 本地 Demo 优先，为 PostgreSQL 迁移预留抽象

### 分层方式
- **api/**：HTTP 路由、请求校验、响应序列化
- **core/**：状态机、事件、AI 解析（核心业务）
- **crawler/**：采集、清洗、去重、核验
- **db/**：ORM、连接、迁移

### 状态机原子性方案
- Application.status 更新 + ApplicationEvent 写入在**同一事务**内
- 使用**悲观锁**（`SELECT ... FOR UPDATE`）处理并发
- 伪代码和时序图已提供

### AI 降级策略
```
LLM 可用 → 解析 → 用户确认 → 入库
    ↓ (不可用)
快捷交互层 → 用户手动选择 → 入库
```
- 成本控制：缓存 + 限流（10次/分钟）+ 超时（5秒）

### 部署形态
- **本地 Demo**：uvicorn + npm run dev，APScheduler 内嵌
- **未来上线**：Vercel（前端）+ 云服务器（后端）+ PostgreSQL（数据库）
