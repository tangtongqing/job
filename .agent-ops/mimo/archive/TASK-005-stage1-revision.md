## 子任务 C：PRD 状态机与数据模型修正

**文件**：`docs/product/PRD.md` → v3

### C.1 状态机修正（采用用户的 9 状态方案 + 主智能体确认的取舍）

**新状态表**：

| 类型 | 状态 | 说明 |
|------|------|------|
| 进行中 | 已投递 | 已提交，等待回复 |
| 进行中 | 测评/笔试 | 收到测评或笔试 |
| 进行中 | 面试中 | 收到面试（可多轮） |
| 进行中 | Offer 待决定 | 收到 Offer，待用户选择 |
| 终态 | Offer 已接受 | 用户接受 |
| 终态 | Offer 已婉拒 | 用户婉拒（`offer_declined`，消除歧义） |
| 终态 | 公司拒绝 | 公司明确拒绝 |
| 终态 | 无回应关闭 | **新增**，超时无回复，用户确认后关闭 |
| 终态 | 主动撤回 | 用户主动撤回 |

**"无回应关闭"触发机制**（主智能体已与用户确认）：
- 系统建议 + 用户确认（不自动转换）
- 阈值：默认 14 天无状态变更，系统在待办中提示"是否标记为无回应关闭"
- 阈值可配置

**状态纠错机制**（主智能体已与用户确认）：
- **终态可纠错 + 留日志**：任何状态（含终态）都允许"撤销上一步"或"纠正"
- 每次纠错写入 ApplicationEvent 日志，标注 `is_correction=true` 和纠错原因
- **漏斗统计必须排除纠错记录**（在 F-B.2 的 AC 中明确）

**修正文档错误**：
- 统一状态数为 9（v2 笔误写成 7 和 8 不一致）
- 修正"Offer-待回复不是终态"的表述
- 明确终态数 = 5（Offer 已接受 / Offer 已婉拒 / 公司拒绝 / 无回应关闭 / 主动撤回）

### C.2 数据模型修正（消除冲突）

**修正 1：删除 `Application.offer_result`**
- 理由：status 已表达 Offer 结果（Offer 已接受/已婉拒），冗余字段会产生矛盾数据
- 改为派生：需要时从 status 推导

**修正 2：`UserJobAction` 只保留维度②，不存"已投递"**
- action_type 取值改为：`收藏` / `待投递`（删除"已投递"）
- 新增 `ended_at` 字段：一旦该岗位创建 Application，原 UserJobAction 记录设 `ended_at`（结案）
- 关系：UserJobAction 是"投递前"的状态，Application 是"投递后"的进度

**修正 3：引入统一事件表 ApplicationEvent（状态与事件分离）**
- 删除 `Application.current_round`（多轮面试靠事件表回溯）
- 新增 `ApplicationEvent` 表（评审建议 + 主智能体确认"统一事件表"方案）：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | |
| application_id | INTEGER FK | 关联投递 |
| event_type | TEXT | `status_change` / `interview` / `test` / `material_submit` / `offer` / `note` / `correction` |
| from_status | TEXT | 状态变更前（仅 status_change/correction） |
| to_status | TEXT | 状态变更后（仅 status_change/correction） |
| round | INTEGER | 面试轮次（仅 interview） |
| scheduled_at | DATETIME | 计划时间（笔试/面试/材料提交的 DDL） |
| occurred_at | DATETIME | 实际发生时间 |
| is_correction | BOOLEAN | 是否纠错记录（默认 false） |
| correction_reason | TEXT | 纠错原因（仅 correction） |
| note | TEXT | 备注 |

- **漏斗数据来源**：F-B.2 漏斗从 `event_type='status_change' AND is_correction=false` 取
- **下一步待办来源**：F-新增"待办视图"从 `event_type IN ('interview','test','material_submit') AND scheduled_at IS NOT NULL AND occurred_at IS NULL` 取
