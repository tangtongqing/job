# 阶段 2 任务流水线 · Stage 2 Pipeline · 架构设计

> 主智能体（Codex）维护。阶段 2 触及后端/数据库/采集/AI，**必须执行 Backend Security & Test Gate**。

---

## 阶段目标

把 PRD v3 的产品定义，转化为**可指导实现的技术架构**：
- 系统分层与部署拓扑
- 数据库物理设计（DDL）
- API 契约
- 采集/AI/状态机的代码层方案
- 安全与测试门禁

## 关键设计原则（Codex 把关）

1. **ApplicationEvent 是命脉**——写入原子性、纠错隔离、查询性能必须在架构层保证
2. **状态机流转必须事务化**——Application.status 更新 + ApplicationEvent 写入必须原子
3. **采集合规优先**——robots.txt 尊重、低频、不绕反爬、不存隐私
4. **AI 解析必须有降级策略**——LLM 不可用时回退到快捷交互层
5. **Demo 边界**——SQLite 本地、无账号、不做高可用，但要为未来 PostgreSQL 迁移留好抽象
