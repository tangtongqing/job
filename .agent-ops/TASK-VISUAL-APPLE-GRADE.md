## 三、从 Apple 提取的设计规律（核心约束，照着做）

### 3.1 最关键：屏级配色呼应（这是"设计美背景"的答案）

Apple **每个 section 用不同的纯色/渐变背景**，颜色取自该屏的产品主题色。

| Apple 做法 | 我们的应用 |
|-----------|-----------|
| 紫色 iPhone → 淡紫色 section 背景 | 信息聚合屏 → 淡蓝（呼应"聚合"） |
| 相机样张 → 深色背景（突出照片） | 数据看板屏 → 深色背景（突出数据） |
| 芯片 → 科技灰背景 | 状态机屏 → 暖灰（中性，突出状态色） |

**要求**：每个 section 配独立的背景色（CSS 即可，亮暗各自一套），打破当前"全站统一背景"的单调。这是用户反馈"背景太单一"的**根因解法**。

### 3.2 真实产品图/视频是绝对主角

Apple 的 section 90% 视觉是产品高清大图/视频，文字只占 10%。

**我们的现实**：产品还没做完，没有真实界面截图。**临时方案**：
- 当前 Hero 的 React mockup（DashboardPreview）继续用，但优化其视觉质感
- 可考虑用 GPT 生图做**呼应主题色的屏级背景**（单屏用，非全站通用图）
- 产品做完后，用真实截图替换 mockup（架构已预留，见 dashboard-data.ts）

### 3.3 字体：超大标题 + 极简文案

| 元素 | Apple 规格 | 我们当前 |
|------|-----------|---------|
| 大标题 | 超大（80-120px），SF Pro，纯黑/纯白 | Instrument Serif + Inter，48-80px |
| 副标题 | 中等，克制 | ✅ 接近 |
| 正文 | 极简，一段不超 2-3 行 | 🟡 可再精简 |
| 数字 | 超大，强调 | ✅ CountUp 已做 |

**要求**：标题可以再大、文案可以再精简。参考 Apple 的"一句话讲清"。

### 3.4 滚动叙事：一屏一功能，全宽大图

Apple 每个功能 = 一个独立 section，全宽展示。我们已做到 7 屏分区，结构对。

**优化点**：滚动时产品的展示方式。Apple 用 scroll 驱动的产品旋转/展开/特写。我们当前是 fade-up，可以升级为：
- scroll-progress 驱动的视差（内容以不同速度移动）
- 产品 mockup 随滚动缩放/位移
- 文字的 scroll-triggered 揭示（更精致的缓动曲线）

### 3.5 巨型多栏 Footer

Apple footer 按"购物/钱包/账户/娱乐/企业/教育/法律"分 7 栏，信息密集。

**要求**：把当前单行 footer 升级为多栏（产品/资源/公司/法律 等），信息更完整。

### 3.6 顶栏与底栏的跳转

| 元素 | Apple 做法 | 我们的应用 |
|------|-----------|-----------|
| 顶栏 logo | 点 → 回首页 | ✅ 已做 |
| 顶栏产品线 | 点 → 对应产品页 | 我们是多分区下拉，点 → 锚点 |
| 顶栏购物袋 | 点 → 购物车/结算 | 我们是"登录"+"免费开始" |
| 底栏 CTA | 每屏底部"Buy" | 我们的 BottomNav 锚点跳转 |

**要求**：确认所有导航链接都有合理跳转目标（锚点或路由），无死链。

## 四、不可推翻的设计约束

这些是和用户反复确认的方向，**不要打破**：

| 约束 | 理由 |
|------|------|
| 真实营销型定位 | 已从"作品集展示型"转向，CTA 用"免费开始" |
| 双主题（亮+暗） | 用户明确要，亮色默认 |
| **不用背景视频** | 已验证视频与多主题冲突 |
| Instrument Serif italic 强调 | 字体灵魂，标题关键词用 `<em>` |
| 每屏布局不同 | 用户强调多元化 |
| 状态色用 CSS 变量 | `--status-applied` 等，亮暗各自调 |
| **反 AI 模板底线** | 禁止：渐变文字/玻璃态/高饱和彩色光团/抽象粒子/"Trusted by" logo 墙 |

### ⚠️ 关于"设计美的背景"（用户特别强调）
用户**明确反对**"AI 味的光带/粒子背景"。Apple 的设计美来自：
1. **屏级配色呼应**（每屏背景色不同，呼应该屏主题）—— 这是核心
2. **极简 + 大留白**（不是元素多，而是克制）
3. **真实内容撑场**（产品图/截图是主角，背景退让）

**不要**用 GPT 生成抽象炫技背景图。如果用生图，只用于"呼应主题色的屏级背景"，且必须能适配双主题。
